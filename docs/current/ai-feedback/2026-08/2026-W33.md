# Agent feedback — 2026-W33

## Fresh independent review found contract contradictions behind a green gate

Date: 2026-08-11
Trigger: a rule caught something you can name

PB8's three fresh-context reviews examined a Portable Binding contract for which the existing
neutral gate passed all 83 vectors. The neutral reviewer nevertheless found that the Composition
handoff schema contradicted the already resolved provider-identity rule, withdrawal promised a legal
late Outcome without defining such a transition, nine vectors had no truthful representation for an
unobservable provider effect count, and no capability had a property quantified over all of its
vectors. The reviews also found stale implementation-target and Channel-execution claims that the
mechanical gate did not check.

When a milestone's evidence is derived from shared declarations, a green artifact/vector gate cannot
substitute for the required fresh-context review: all consumers can agree with the same incorrect or
silent declaration. Preserve the first negative attestations, pin each finding with a gate or native
regression before correcting it, and require a fresh re-review of the corrected commit.
